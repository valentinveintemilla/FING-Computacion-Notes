# Ejercicio 5
Primero, analicemos que pasa en la función para $x = 1$:
$$
\begin{align}
&a + b + \sin\left( \frac{\pi}{2} \right) = a + b + 1 \\
&b + 1 + \cos(\pi) = b + 1 - 1 = b
\end{align}
$$
De esta forma, tenemos que calcular la siguiente igualdad:
$$
\begin{align}
&a + \cancel{ b } + 1 = \cancel{ b } \\
&a + 1 = 0 \\
&a = -1
\end{align}
$$
Es así que la función $f$ es continua si:
$$
a = -1, \forall b \in \mathbb{R}

# Ejercicio 8
Gracias al enunciado, sabemos que
$$
\lim_{ x \to 3 f(x) = 0}
$$
Aplicando propiedades de límite, podemos desarrollar la operación:
$$
\lim_{ x \to 3 } \lfloor x + 2 \rfloor f(x) = \lim_{ x \to 3 } \lfloor x + 2 \rfloor \times \lim_{ x \to 3 } f(x)
$$
Sin embargo, si intentamos calcular $\lim_{ x \to 3 } \lfloor x + 2 \rfloor$, veremos lo siguiente:
$$
\begin{align}
&\lim_{ x \to 3^{-} } \lfloor x + 2 \rfloor = 4 \\
&\lim_{ x \to 3^{+} } \lfloor x + 2 \rfloor = 5
\end{align}
$$
Por lo tanto, la función $\lfloor x + 2 \rfloor$ no tiene límite para $x = 3$. En conclusión, la función $\lfloor x + 2 \rfloor f(x)$ no tiene límite para $x = 3$.
