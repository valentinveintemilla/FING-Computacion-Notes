# Ejercicio 2
Estudiemos la intersección entre ambos:
$$
W_{1} \cap W_{2} = \left\{ (x, y, z) \in \mathbb{R}^{3} : \begin{cases}
x + y - 3z = 0 \\
x - y = 0
\end{cases} \right\}
$$
De esta forma, definimos una recta, la cual tiene un solo vector director, descartando las opciones C y E.

Tenemos que considerar un vector director conformado por la intersección de ambos planos. Por lo tanto, tomaremos dos puntos de la intersección:

En base a la segunda ecuación: $x - y = 0 \implies x = y$

Podemos sustituir $x$ por $y$ en la ecuación 1:
$$
x + y - 3z = 0 \implies 2y - 3z = 0 \implies 2y = 3z \implies y = \frac{3}{2}z
$$
Entonces, podemos considerar $x = y = 1$:
$$
y = 1 \implies \frac{3}{2}z = 1 \implies z = \frac{2}{3}
$$

De esta manera, un punto de la recta es $\left( 1, 1, \frac{2}{3} \right)$

Ahora, consideremos $y = 0$:
$$
y = 0 \implies \frac{3}{2}z = 0 \implies z = 0
$$
La recta vectorial pasa por el $(0, 0, 0)$ (trivial).

Entonces, podemos considerar el vector:
$$
\left( 1, 1, \frac{2}{3} \right) - (0, 0, 0) = \left( 1, 1, \frac{2}{3} \right)
$$

Entonces, cualquier múltiplo de dicho vector puede formar una base del la intersección $W_{1} \cap W_{2}$, por ejemplo el vector $(3, 3, 2)$

# Ejercicio 9
Primero determinemos si la suma es o no directa. Para esto, tenemos que estudiar la intersección entre ambos conjuntos, teniendo que ser únicamente 0:
$$
S_{1} \cap S_{2} \overset{?} = \vec{0}
$$
Tenemos que verificar cual es la forma de los polinomios del espacio $S_{1}$:
$$
p(0) = p(2) = 0
$$
Entonces tienen raíces en 0 y 2 (al menos).

Consideremos la forma genérica $p(x) = ax^{3} + bx^{2} + cx + d$, teniendo que verificar:
$$
\begin{cases}
p(0) = 0 \\
p(2) = 0
\end{cases}
$$
$$
p(0) = \cancel{ a \cdot 0^{3} + b \cdot 0^{2} + c \cdot 0 } + d = d \implies d = 0
$$
$$
p(2) = 8a + 4b + 2c + d = 0
$$
Sabiendo que $d = 0$:
$$
\begin{align}
8a + 4b + 2c &= 0 \\
4a + 2b + c &= 0
\end{align}
$$
También lo podemos estudiar para polinomios de grado menor:
$$
2b + c = 0
$$
para polinomios de segundo grado.

La pregunta es, ¿Podemos conformar un polinomio que tenga estas características considerando el subespacio $S_{2}$?

El espacio $S_{2}$ tiene como base $\{ x^{2} - 2x, x^{3} \}$

Cualquier polinomio conformado por los anteriores cumple que $p(0) = 0$, pero necesitamos que también tenga raíz en 2.

Entonces, la intercepción entre ambos subespacios no es únicamente el vector nulo, por lo que la suma no será directa (descartando las opciones A y D).
