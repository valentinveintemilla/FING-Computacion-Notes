Determinamos las derivadas de $y(x)$:
$$
y(x) = e^{2x} \cos(x)
$$
$$
y'(x) = 2e^{2x} \cos(x) - e^{2x} \sin(x)
$$
$$
y''(x) = 3e^{2x} \cos(x) - 4e^{2x} \sin(x)
$$

Sustituimos en la ecuación presentada:
$$
\begin{align}
y'' + ay' + by &= 0 \\
(3 + 2a + b)e^{2x} \cos(x) + (-4 - a)e^{2x} \sin(x) &= 0 \\
\end{align}
$$

Resolvemos el sistema correspondiente:
$$
\begin{cases}
3 + 2a + b = 0 \implies 2a + b = -3 \\
-4 - a = 0 \implies a = -4
\end{cases} \implies -8 + b = -3 \implies b = 5
$$

En conclusión, $a = -4$ y $b = 5$.

## Ejercicio 3
Clasificar las series:
$$
\sum_{n = 1}^{\infty} \frac{\log(n)}{e^{n}}
$$
Apliquemos el criterio de la raíz enésima:
$$
\begin{align}
\lim_{ n \to \infty } \sqrt[n]{ \frac{\log(n)}{e^{n}} } &= \lim_{ n \to \infty } \frac{\sqrt[n]{ \log(n) }}{\sqrt[n]{ e^{n} }} \\
&= \lim_{ n \to \infty } \frac{\sqrt[n]{ \log(n) }}{e} \\
&= \frac{1}{e} \cdot \lim_{ n \to \infty } \sqrt[n]{ \log(n) }
\end{align}
$$
Para evaluar $\sqrt[n]{ \log(n) }$, podemos considerar que:
$$
1 < \log(n) < n \implies \sqrt[n]{ 1 } < \sqrt[n]{ \log(n) } < \sqrt[n]{ n }
$$
Y estudiamos los límites:
$$
\begin{align}
&\lim_{ n \to \infty } 1^{\frac{1}{n}} = 1 \\
&\lim_{ n \to \infty } n^{\frac{1}{n}} = 1
\end{align} \implies \lim_{ n \to \infty } \sqrt[n]{ \log(n) } = 1
$$
Finalmente:
$$
\lim_{ n \to \infty } \sqrt[n]{ \frac{\log(n)}{e^{n}} } = \frac{1}{e} \cdot \lim_{ n \to \infty } \sqrt[n]{ \log(n) } = \frac{1}{e} \cdot 1 = \frac{1}{e} < 1
$$

De esta manera, por el criterio de la raíz enésima, la serie $\sum_{n = 1}^{\infty} \frac{\log(n)}{e^{n}}$ es convergente.

## Ejercicio 4
Tenemos que determinar una primitiva de $\tan(x)$. Aplicamos sustitución considerando que
$$
\tan(x) = \frac{\sin(x)}{\cos(x)}
$$
$$
u = \cos(x) \implies du = -\sin(x) dx
$$
$$
\int \tan(x) dx = \int \frac{\sin(x)}{\cos(x)} dx = -\int \frac{-\sin(x)}{\cos(x)} dx \underbrace{ = }_{ C.V } -\int \frac{1}{u} du = -\log(u) = -\log(\cos(x))
$$
Entonces:
$$
\begin{align}
\int_{0}^{\frac{\pi}{2}} \tan(x) dx &= -\left( \log(\cos(x)) |_{0}^{\frac{\pi}{2}} \right) \\
&= -\left( \log\left( \cos\left( \frac{\pi}{2} \right) \right) - \log(\cos(0)) \right) \\
&= -\left( \lim_{ x \to 0 } \log(x) - \log(1) \right) \\
&= -\left( -\infty \right) \\
&= +\infty
\end{align}
$$

En conclusión, la integral $\int_{0}^{\frac{\pi}{2}} \tan(x) dx$ es divergente.

## Ejercicio 1
Tenemos que probar que $\lim_{ n \to \infty } \frac{1}{n} = 0$.

Para esto, tenemos que probar que
$$
\forall \epsilon > 0, \exists n_{0} \in \mathbb{N} \text{ tal que } \forall n \geq n_{0}, \left| \frac{1}{n} \right| < \epsilon
$$

Básicamente, aprovechando la desigualdad $\left| \frac{1}{n} \right| < \epsilon$, tenemos que encontrar un $n$ genérico basado en $\epsilon$ tal que, para cualquier valor de $\epsilon$ dado, a partir de dicho $n$ la sucesión se encuentre en el entorno $E(0, \epsilon)$:
$$
\begin{align}
\left| \frac{1}{n} \right| &< \epsilon \\
\frac{1}{n} &< \epsilon \\
n &> \frac{1}{\epsilon}
\end{align}
$$
De esta forma, basta con tomar el primer $n$ que sea mayor que $\frac{1}{\epsilon}$, y a partir de dicho $n$, todos los elementos de la sucesión pertenecerán al entorno mencionado.

## Ejercicio 2
### Parte a
Hipótesis:
- $\lim_{ n \to \infty } a_{n} = L \in \mathbb{R}$
- $\lim_{ n \to \infty } (a_{n} - b_{n}) = 0$

Tesis:
- $\lim_{ n \to \infty } b_{n} = L$

Considerando las hipótesis, podemos decir que
$$
\forall \epsilon > 0, \exists n_{1} \in \mathbb{N} \text{ tal que } \forall n \geq n_{1}, \left| a_{n} - L \right| < \epsilon
$$
$$
\forall \epsilon > 0, \exists n_{2} \in \mathbb{N} \text{ tal que } \forall n \geq n_{2}, \left| a_{n} - b_{n} \right| < \epsilon
$$

Consideramos $n_{3} = \max \{ n_{1}, n_{2} \}$, tal que a partir del mismo, ambas condiciones se verifican al mismo tiempo:
$$
\left| a_{n} - L \right| < \epsilon \land \left| a_{n} - b_{n} \right| < \epsilon
$$
Como lo anterior se cumple $\forall \epsilon > 0$, entonces a partir de un $n_{3}$ determinado se cumple para $\frac{\epsilon}{2}$:
$$
\left| a_{n} - L \right| < \frac{\epsilon}{2} \land \left| a_{n} - b_{n} \right| < \frac{\epsilon}{2}
$$
Finalmente, considerando $\left| a_{n} - b_{n} \right| = \left| b_{n} - a_{n} \right|$, sumamos las desigualdades:
$$
\left| a_{n} - L \right| + \left| b_{n} - a_{n} \right| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon
$$
Y por desigualdad triangular:
$$
\left| a_{n} - L \right| + \left| b_{n} - a_{n} \right| \geq \left| \cancel{ a_{n} } - L + b_{n} - \cancel{ a_{n} } \right| = \left| b_{n} - L \right|
$$
Y por transitividad:
$$
\left| b_{n} - L \right| \leq \left| a_{n} - L \right| + \left| b_{n} - a_{n} \right| < \epsilon
$$

En conclusión,
$$
\forall \epsilon > 0, \exists n_{0} \in \mathbb{N} \text{ tal que } \forall n \geq n_{0}, \left| b_{n} - L \right| < \epsilon
$$
por lo que
$$
\lim_{ n \to \infty } b_{n} = L
$$

### Parte b
Hipótesis:
- $\lim_{ n \to \infty } a_{n} = +\infty$
- $\exists m > 0$ tal que $m < b_{n}$, $\forall n \in \mathbb{N}$.

Tesis:
- $\lim_{ n \to \infty } a_{n} \cdot b_{n} = +\infty$

Nuestro objetivo es probar que $\lim_{ n \to \infty } b_{n}$ (en caso de existir) es diferente de 0.

Como sabemos que $\exists m > 0$ tal que $m < b_{n}$, $\forall n \in \mathbb{N}$, entonces $b_{n} > 0, \forall n \in \mathbb{N}$ (pues $b_{n}$ se encuentra acotada inferiormente por un valor positivo).

De esta manera, el único problema podría ocurrir si $\lim_{ n \to \infty } b_{n} = 0$.

Para que esto ocurra, se tiene que verificar:
$$
\forall \epsilon > 0, \exists n_{0} \in \mathbb{N} \text{ tal que } \forall n \geq n_{0}, \left| b_{n} \right| < \epsilon
$$
lo que indica que $b_{n}$ se acercaría a 0 infinitamente. Sin embargo, esto es imposible, ya que si $b_{n} \in E(L, \epsilon), \forall n \geq n_{0}$, en algún momento se cumpliría $b_{n} \leq m$.

Por lo tanto, es absurdo pensar que $\lim_{ n \to \infty } b_{n} = 0$, entonces necesariamente $\lim_{ n \to \infty } b_{n} > 0$ (si existiera).

Demostración real:

Como sabemos que $b_{n} > m$, entonces necesariamente:
$$
\lim_{ n \to \infty } a_{n} \cdot b_{n} > \lim_{ n \to \infty } a_{n} \cdot m = m \cdot \lim_{ n \to \infty } a_{n}
$$

Ahora, sabiendo que $m > 0$, entonces no nos encontramos ante una indeterminación, por lo tanto:
$$
m \cdot \lim_{ n \to \infty } a_{n} = +\infty
$$

En conclusión, determinamos que $\lim_{ n \to \infty } a_{n} \cdot b_{n} = +\infty$

### Ejercicio 3
Teniendo la sucesión $\frac{1}{n}$, consideramos la función real correspondiente, la cual es continua, positiva y monótona decreciente (probarlo mediante su derivada) $\frac{1}{x}$ (en el intervalo presentado $[1, +\infty)$), entonces podemos aplicar el criterio Serie-Integral:
Sea $f : [k, +\infty) \to \mathbb{R}$ monótona decreciente, y $f(x) \geq 0, \forall x$. Entonces $\sum_{n = k}^{+\infty} f(n)$ y $\int_{k}^{+\infty} f(x) dx$ son de la misma clase.

Consideremos la integral correspondiente $\int_{1}^{+\infty} \frac{1}{x} dx$, y determinemos su divergencia:

Conocemos una primitiva de $\frac{1}{x}$: $\log(x)$. Por lo tanto:
$$
\begin{align}
\int_{1}^{+\infty} \frac{1}{x} dx &= \log(x) |_{1}^{+\infty} \\
&= \lim_{ x \to +\infty } \log(x) - \log(1) \\
&= +\infty - \log(1) \\
&= +\infty
\end{align}
$$
De esta manera, la integral $\int_{1}^{+\infty} \frac{1}{x} dx$ es divergente.

Como $\frac{1}{x}$ cumple todas las condiciones para aplicar el criterio Serie-Integral, concluimos que $\int_{1}^{+\infty} \frac{1}{x} dx$ y $\sum_{1}^{+\infty} \frac{1}{n}$ son de la misma clase, y por lo tanto, $\sum_{1}^{+\infty} \frac{1}{n}$ es divergente.
